===== statsai --help =====
Local-first AI usage stats CLI/SDK/daemon.

Usage: statsai [OPTIONS] <COMMAND>

Commands:
  scan          Scan local provider sources for usage events
  report        Show usage reports (weekly, monthly, all-time, or a date range)
  source        Manage configured source paths
  account       List canonical provider accounts
  subscription  Manage subscription periods
  import        Import external usage summaries
  export        Export stored events as JSON
  task          Review and rebuild local work items
  conversation  Collect and explore durable local conversation archives
  quota         Inspect reconstructed provider quota history
  privacy       Build and inspect the local privacy-filtered dataset
  sync          Export a sync batch to a sink
  schema        Print JSON schemas for backend-facing contracts
  store         Manage the local SQLite store
  daemon        Start the loopback API daemon
  status        Show stored event and token counts
  doctor        Check environment and source paths
  auth          Authenticate with the hosted sync backend
  service       Install or manage the background daemon service
  snapshot      Show link, sync, and background collection status
  help          Print this message or the help of the given subcommand(s)

Options:
      --store <STORE>          Path to SQLite store
      --device-id <DEVICE_ID>  Device identifier for multi-device sync
  -h, --help                   Print help
  -V, --version                Print version
===== statsai scan --help =====
Scan local provider sources for usage events

Usage: statsai scan [OPTIONS]

Options:
      --provider <PROVIDER>    Scan only this provider
      --store <STORE>          Path to SQLite store
      --device-id <DEVICE_ID>  Device identifier for multi-device sync
      --include-tasks          Collect local task spans and rebuild work items
      --preview                Preview without persisting to the store
      --no-cache               Ignore the scan file cache and reparse all candidate files
      --replace                Replace existing events for scanned sources before inserting
      --verbose                Show detailed per-source diagnostics
      --explain                Show parse evidence for each event
  -h, --help                   Print help

===== statsai sync --help =====
Export a sync batch to a sink

Usage: statsai sync [OPTIONS]

Options:
      --sink <SINK>              Sync sink (stdout, file, http) [default: stdout]
      --store <STORE>            Path to SQLite store
      --device-id <DEVICE_ID>    Device identifier for multi-device sync
      --output <OUTPUT>          Output path for file sink
      --endpoint <ENDPOINT>      HTTP endpoint for the http sink (defaults to STATSAI_API_URL/api/sync/batches)
      --auth-token <AUTH_TOKEN>  Bearer token override for the http sink
      --rebuild-rollups          Rebuild local daily rollups from events and force all rollups dirty before sync
      --full                     Force a full HTTP rollup sync even when this target was synced before
      --since-last               Send only records after this sink target's last successful sync
      --status                   Show recorded sync state instead of sending
      --verify                   Inspect the resolved Cloudflare sync target and verify remote device access
      --reset-remote             Delete mirrored hosted sync data for this paired device and clear local sync tracking (http only)
      --yes                      Confirm destructive sync reset actions
      --dry-run                  Build the sync batch without writing
      --include-projects         Enable project metadata sync for this device and future syncs
      --exclude-projects         Disable project metadata sync for this device and future syncs
      --include-tasks            Enable hosted task sync for this device and future syncs (implies --include-projects)
      --exclude-tasks            Disable hosted task sync for this device and future syncs
  -h, --help                     Print help
